## Milestones

1. Response integrity (current runtime paths covered): shared structured/freetext agents, reflector, all direct analysts/debaters and optional batch narrator inspect known completion metadata and reject unusable output with one bounded generation retry. Tool-capable analysts distinguish well-formed tool requests from final prose before publishing state; accepted envelopes/IDs are preserved. Failed reflections remain pending. Structured binding requests raw metadata. Missing provider metadata remains inconclusive.
2. Decision integrity (complete): graph signals and batch results use strict explicit-label/bare-rating parsing; invalid/conflicting decisions yield REVIEW and are not stored as learnable decisions. Invalid legacy records remain readable but are excluded from resolution/context; they cannot block corrected decisions. The legacy display heuristic remains for compatibility.
3. Outcome integrity (complete): match asset/benchmark endpoint session dates, reject missing/duplicate/invalid prices, persist full-precision returns and deterministic direction/relative classifications in an additive outcome object (scoring_version=1). Record actual evaluation start/end, session count, and benchmark. Sell means exit/avoid, not an executed short; Hold scores are not_applicable. Reflections receive classifications and must acknowledge insufficient causal evidence. Same/cross-ticker contexts expose scores separately from LLM prose. Legacy outcomes are not automatically regraded.
4. Memory isolation (complete): runtime graph and GUI reads/resolution use explicit cutoffs bounded by min(run date, today), and live/simulation namespaces. New JSONL writes use version 2; untagged records remain legacy (audit-readable, not implicitly live). Namespace is part of deduplication, outcome-update keys, rotation budgets, and checkpoint identity. Config memory_namespace=auto selects live only for today's date; live/simulation overrides support simulations dated today. No bulk migration was executed.
5. Historical tool boundaries (complete, conservative availability policy): LangGraph InjectedState supplies hidden trusted state to dated tools; endpoints are capped at min(requested date, run date, today), and ranges starting beyond the cutoff are rejected. Omitted statement dates inherit the run cutoff. News, prices, indicators, verified snapshots, fundamentals and macro tools are covered; sentiment prefetch also caps future dates. Historical prediction markets/insider enrichment and current identity lookups are withheld. Both statement adapters withhold historical requests before network access because neither establishes publication dates plus as-published vintages/restatements. No replacement historical filing provider was added. Checkpoint identity includes the new tool policy.
6. News evidence (deterministic foundation complete): run-local request snapshots shared across sentiment prefetch and news tools, stable evidence IDs and URL-based deduplication, correct vendor/publisher provenance and publication timestamps, typed failures that permit configured fallback, and explicit bounded-coverage notices. News/sentiment and downstream synthesis prompts require preserving IDs and counting repeated evidence once; model compliance is not guaranteed.
7. Social evidence (deterministic controls complete): Reddit defaults to 15 candidates per subreddit (maximum 100); StockTwits retains at most 30 posts from one bounded candidate page. Both sources remove repeated IDs/normalized text and retain at most three posts per known author, with counts/exclusions and concentration metadata. Reddit controls span subreddits and RSS preserves author/post identity. Missing authors are disclosed, not grouped into one account or asserted independent. StockTwits percentages use only retained labeled posts and expose label coverage; zero labels means unavailable, not neutral. Prompt instructions acknowledge missing engagement, selection bias and unverified account quality.
8. Prompt boundaries (runtime serialization controls complete): external analyst evidence and instrument profiles are separate human/tool messages, never system content. A shared boundary helper escapes delimiters, removes selected control/bidi characters, bounds evidence/history content and marks truncation. State-supplied system/developer messages are demoted to evidence. Reused reports, debate arguments, memory lessons, reflection decisions and batch summaries are also delimited/bounded. Tool-call/result identity and stored state are preserved. Regression scenarios verify these boundaries, not immunity to semantic prompt injection.
9. Prompt/debate bias (deterministic controls complete; representative empirical evaluation pending): removed Nvidia examples and analyst trade-proposal instructions; Neutral includes substantive balanced/non-directional evidence, while missing evidence is an explicitly low-confidence unassessed placeholder. Every debate participant receives an independent opening and equal completed-round rebuttal opportunities. Judges receive fixed-order, separately bounded role histories. Offline counterbalanced prompt checks pass. An authorized single-model synthetic pilot now records rating variation in the adverse case; repeated controls and representative evaluation remain pending (see live-pilot findings below).

10. Frozen-evidence evaluation (offline harness and initial local live pilot complete; representative measurements pending): shared Portfolio Manager prompt builder, all six role orders crossed with isolated injected-source variants and repeats, deterministic frozen plans, hash-bound response replay, explicit live opt-in/call budgets, paired rating-flip denominators, unusable-output counts and lexical citation observations. Production role order/prompt behavior is unchanged. See EVALUATION.md.

11. Evaluation corpus preparation (synthetic acceptance slice complete; real evidence/recording review pending): four invented scenarios with scripted responses, an offline corpus command, checked per-case metrics, explicit synthetic provenance, and failure/no-overwrite guards. This is not an empirical evaluation or an independently reviewed investment benchmark.
