## Completion status and limits

1. The approved 72-call repeated-prompt evaluation is complete: six trials of clean/injected evidence in all six orders, all valid, with offline-reproducible metrics. See `evaluation_runs/local-luna-repeat-20260908T214532743256Z/REPORT.md`.
2. Identical-prompt variation was substantial (26/60 reference comparisons). This shows that prompt changes are not required for rating flips; it does not prove that order/injection effects are absent. Shared references make comparisons dependent, and rates must not be subtracted to claim causal improvement.
3. All original code work and the agreed verification runs have been performed. A whole-system pre/post accuracy benchmark and independent human adjudication have not been performed; proven reduction in bias or manipulation should not be marked complete merely because evaluation execution is complete. Further live work requires a new authorization.

A historical filing provider, universal token-aware budgets and a broad multi-model benchmark are sensible future work, but they should not be retroactively substituted for the original 14 tasks. Earlier statements that all phases were complete were too broad.

## Subsequent recommendation: human review and consistency

The user subsequently requested implementation of mandatory human review plus an exposure-decision consistency check. This is a follow-up, not a new numbered task or proof that task 14's effectiveness criterion is satisfied.

Standard graph runs now return REVIEW even for unanimous or Hold proposals. Exposure-changing proposals permit up to two additional prompt-isolated checks using identical frozen analyst evidence, with visible source quotes and acknowledged gaps required. Disagreement and unusable output remain REVIEW. The original proposal, checks and prompt are retained in `decision_review`; reports lead with a warning and export its JSON. Batch allocation rejects reviewed/invalid results, and unapproved decisions do not enter new learning. Checkpoint identity adds `decision_review_policy=1`.

`tests/test_decision_review.py` adds 32 offline cases, including actual graph/checkpoint behavior and LangChain fake-model invocations. No live calls were made. See `DECISION_REVIEW.md` for costs, bounds, custom-call limitations and the genuine-evidence validation checklist. Approval is manual outside the application; no authenticated approval API exists. The existing frozen evaluation still measures the underlying Portfolio Manager proposal prompt, not the new gate. Representative genuine snapshots and independent adjudication remain pending, and all earlier live budgets remain exhausted.
